# 대중음악 리듬 수업 자료 (2026 KMET · 10. 24.)

AI 시대 전자음악 창작을 위한 디지털 사운드 리터러시 — 대중음악 리듬을 중심으로
김서희 · 연세대학교 글로벌인재학부 강사

## 여는 곳
- `index.html` — 첫 화면(전체 목록)
- `1교시 교안.html` — 장르는 귀로 증명한다
- `2교시 교안.html` — 대중음악 리듬의 정의와 실습

## 폴더
| 위치 | 내용 |
|---|---|
| `clips/` | 교안이 재생하는 음원·영상 구간(mp3, mp4) |
| `img/` | 그림, 강사 소개 |
| `네 부족의 북_v1.mp4` | 1교시 영상 |
| 나머지 `.html` | 실험실 · 장르 계보 (교안 안에서 열림) |

파일 이름·위치를 바꾸면 교안 안의 연결이 끊깁니다. 폴더 통째로 올리세요.

## GitHub에 올리고 링크 만들기
1. GitHub에서 새 저장소(Public) 만들기
2. 이 폴더 **안의 내용 전부**를 올리기
   - 웹 업로드는 한 번에 100개까지 → 2~3번에 나눠 끌어다 놓기 (`clips` 폴더는 따로 한 번)
   - 또는 GitHub Desktop으로 한 번에
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 이 첫 화면 주소

## 기기 호환
- 영상: H.264 + AAC, 빠른 시작(faststart) — 아이폰·아이패드·갤럭시·PC 브라우저 모두 재생
- 음원: MP3
- 휴대폰은 첫 터치 전 소리를 막으므로 화면을 한 번 누른 뒤 재생
- 아이폰 무음 스위치 상태에서도 소리가 나도록 각 페이지에 설정 추가
- 정답 공개 키(K 등)는 키보드 있는 PC 전용
